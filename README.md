# Eclipse Rift — ต้นแบบเกมการ์ดแนว Roguelike Deckbuilding RPG

เกมการ์ดแนว anime ทีมละ 3 คน โหมดหลักคือ **CHAOS RIFT** ลงดันแบบโร้กไลก์
เดินบนแผนที่แยกทาง สร้างเด็คระหว่างทาง และล่าบอส 2 ชั้น
ตัวละครแสดงเป็นโมเดล 3D แบบ toon shading

## วิธีเปิดเล่น

```bash
python -m http.server 5173
```

เปิด http://localhost:5173
เกมโหลด Three.js จาก cdnjs มาวาดตัวละคร 3D ถ้าโหลดไม่ได้จะใช้ภาพ 2D แทนโดยอัตโนมัติ
สลับ 3D/2D ได้ที่หน้าหลัก

## CHAOS RIFT (โหมดหลัก)

| ระบบ | รายละเอียด |
|---|---|
| แผนที่ | 2 ชั้น (รอยแยกชั้นนอก → แก่นรอยแยก) ชั้นละ 7 ขั้น เลือกเส้นทางได้เอง |
| จุดบนแผนที่ | ต่อสู้ · อีลีท · ปริศนา (เหตุการณ์/สมบัติ/ต่อสู้) · จุดพัก · ร้านค้า · บอส |
| HP | ติดตัวไปทุกด่าน ฟื้นได้ที่จุดพัก เหตุการณ์ และหลังผ่านบอสชั้นแรก |
| เด็ค | เริ่มจากการ์ดของ 3 ตัวละคร (12 ใบ) ชนะแล้วเลือก 1 ใน 3 ใบจากพูลของทีม · ซื้อหรือลบการ์ดได้ที่ร้าน |
| Epiphany | การ์ดแต่ละใบตื่นรู้ได้ 1 ครั้ง: Swift (AP −1), Empowered (+35%), Insight (จั่ว +1), Guarded (โล่ 5), Steadfast (เก็บในมือ), Resonant (LINK 2+ ×1.6) |
| ความเครียด | เพิ่มตามดาเมจที่โดน ถึง 100 จะ **Mental Breakdown** (ตีเบาลง โดนแรงขึ้น) ต้องเล่นการ์ดของตัวนั้น 4 ใบเพื่อฟื้น แล้วทีมได้ Burst 40% |
| Fragment | ไอเทมติดตัวตลอดรอบ 11 แบบ ได้จากอีลีท บอส ร้านค้า และสมบัติ |
| ศัตรู | มอนสเตอร์ 7 แบบ + บอส Hollow Seraph และ Malvoth ทุกตัวประกาศท่าล่วงหน้า (INTENT) |
| ระดับ | Chaos 1–3 · ผ่านแล้วได้คริสตัล หัวใจปีศาจ และอาวุธ |

ผลจำลอง (`tools/sim.js`): ทีมใหม่ Lv 1 ผ่าน Chaos 1 ได้ประมาณ 27% ทั้งที่บอทเลือกเส้นทางและการ์ดแบบสุ่ม
คนที่เลือกเองอย่างตั้งใจน่าจะผ่านได้บ่อยกว่านั้น · Chaos 2 ต้องใช้ทีมราว Lv 15

## การ์ด: 5 ตัวละคร × 12 ใบ (60 ใบ)

แต่ละตัวมีการ์ดเริ่มต้น 4 ใบ และการ์ดที่ได้ระหว่างดัน 8 ใบ (Common / Rare / Epic)

| ตัว | แนวการเล่น | ตัวอย่างคอมโบ |
|---|---|---|
| Kael | สะสมโล่แล้วเปลี่ยนเป็นดาเมจ · สวนกลับ | Unbreakable (โล่ 16) → Judgement Aegis (ตีศัตรูทุกตัวเท่ากับโล่) |
| Aria | สะสม **โมเมนตัม** แล้วปิดด้วยท่าแรง | Slash, Swift Draw → Final Petal (+6 ต่อโมเมนตัม) |
| Lumi | ฮีล ฟื้นฟูต่อเนื่อง แจกพลัง ชุบชีวิต | Valor Prayer (ทุกคน +1 พลัง) → Blossom Storm / Volley ที่ตีหลายครั้ง |
| Noir | สะสมกัดกร่อนแล้วจุดระเบิด | Venom Sigil → Eclipse Sigil (×2) → Detonate Curse |
| Rin | ล็อกเป้า เพิ่ม AP จั่วการ์ด เล็งให้เพื่อน | Lock On ให้ Aria → Crimson Iaido แรง ×2 |

คีย์เวิร์ดใหม่: **LINK 2+** (ผลเสริมเมื่อสลับตัวต่อเนื่อง), **ต่อเนื่อง** (ผลเสริมถ้าการ์ดก่อนหน้าเป็นการโจมตีของเพื่อน),
โมเมนตัม, สวนกลับ, ฟื้นฟูต่อเนื่อง, เล็งเป้า, และการ์ดที่แรงขึ้นตามจำนวนสถานะบนเป้า

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `src/data.js` | **ตัวเลขทั้งหมด** การ์ด ตัวละคร มอนสเตอร์ Epiphany Fragment เหตุการณ์ ค่าความยาก |
| `src/engine.js` | ระบบต่อสู้ (deterministic) รวมคอมโบ ความเครียด และ Epiphany |
| `src/run.js` | ระบบ Chaos Rift: แผนที่ รางวัล ร้าน จุดพัก เหตุการณ์ |
| `src/progression.js` | เลเวล / Awakening / อาวุธ → ค่าพลังในการต่อสู้ |
| `src/ai.js` | บอท และศัตรูที่เล่นตาม INTENT |
| `src/art3d.js` | ตัวละคร 3D (Three.js): toon shading, เส้นขอบ, แสงขอบ, กระพริบตา, ขยับตามเมาส์ |
| `src/art.js` | ภาพ 2D (ใช้เมื่อปิด 3D) + มอนสเตอร์ + ไอคอน |
| `src/ui/*.js` | หน้าจอ: `chaos` `battle` `screens` `raid` `online` `core` |
| `tools/sim.js` | ตัวจำลองไว้ปรับสมดุล (ดูวิธีใช้ในหัวไฟล์) |

## เรื่องภาพตัวละคร

ตัวละคร 3D ตอนนี้โค้ดประกอบขึ้นจากรูปทรงง่ายๆ ได้หน้าตาออกแนว chibi / Nendoroid
ถ้าอยากได้ตัวละคร 3D สวยระดับเกมขายจริง ทางที่ทำได้จริงคือ:

1. **VRoid Studio** (ฟรี จาก pixiv) ปั้นตัวละคร anime 3D เองได้โดยไม่ต้องวาดเป็น แล้ว export เป็นไฟล์ `.vrm`
   ต่อเข้าเกมได้ด้วย `@pixiv/three-vrm` ซึ่งใช้ Three.js ตัวเดียวกับที่เกมใช้อยู่
2. จ้างนักวาดหรือนักปั้นโมเดล แล้วทำแอนิเมชันด้วย Spine / Live2D / Unity
3. ภาพ 2D: วางไฟล์ไว้ที่ `assets/characters/` แล้วตั้งค่าใน `ART` ของ `src/data.js`
